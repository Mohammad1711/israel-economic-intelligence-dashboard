# 🇮🇱 Israel Economic Intelligence Dashboard

A data analytics and automation project built with Python, Pandas, and the Bank of Israel public API.

The project automatically extracts exchange-rate data, processes economic indicators, generates operational insights, stores historical records, and creates automated reports and visualizations.

---

# Technologies Used

* Python
* Pandas
* Requests
* XML Parsing
* Matplotlib
* Bank of Israel API

---

# Features

✅ Real-time API integration
✅ Exchange-rate monitoring
✅ Automated daily reports
✅ Historical economic database
✅ Trend visualization
✅ Automated insight generation

---

# Workflow

Bank of Israel API
→ Python Data Extraction
→ Data Cleaning & Analysis
→ Historical Data Storage
→ Automated Reports
→ Visualization
